# 项目接入与设计体系原型

本轮按新的产品流程调整独立原型，没有修改正式页面。三种主页布局保留：逐步引导、双栏工作台、紧凑清单；后续设计体系使用同一份演示，便于集中比较主页布局。

## 如何体验

先命名并创建项目空间，阅读初始化说明，再复制示例命令。点击“模拟初始化完成”，查看网页和终端结果示意，然后进入设计体系。

设计体系可以选择沿用现有主题或使用产品主题。调整主色、圆角、间距观察示例预览；使用产品主题时，先为活动强调色选择映射或新增保留，再生成待应用版本。

生成版本后修改草稿，旧命令仍对应旧版本。可以生成新版本，并模拟应用成功或本地文件冲突。页面不写入任何真实项目文件。

侧栏顶部可以创建和切换项目空间；窄屏时切换器在顶栏下方。不同空间保留独立草稿和版本，同名空间有不同编号。刷新、切换设计方案或重置演示会清空模拟项目。

顶部可以模拟找到主题、无主题、等待接入和命令过期。没有主题也能选择产品主题继续，过期时重新生成初始化命令。

## 运行与验证

在仓库根目录运行以下命令，然后打开 `/prototypes/home/`（原型地址）：

```powershell
node apps/web/node_modules/vite/bin/vite.js --config apps/web/prototypes/home/vite.config.ts --configLoader runner --host 127.0.0.1 --port 5183 --strictPort
```

底部或数字键 1–3 切换方案，左右方向键也可以切换，R（重置快捷键）重新开始当前方案。输入时不触发这些快捷键。

`verify-flow.js`（流程验证脚本）覆盖三种布局中的初始化、过期重试、主题映射、版本固定、应用冲突、无主题接入、同名项目隔离和窄屏布局。浏览器截图保存在输出目录。

## 演示边界

项目、变量、引用统计和应用结果均为模拟数据。命令参数尚未定稿，不能执行。当前只展示有代表性的变量和一条语义关系，不是完整设计编辑器；示例预览不能代表用户整个项目的实际效果。

原型复用现有控件和固定控制台主题。用户草稿只影响独立预览。真实接口、持久化、引用分析、文件迁移和恢复机制仍待实现。选定后由用户逐步实现正式页面，本轮不自动整合。
